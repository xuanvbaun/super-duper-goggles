================================================================
     工艺清单生成程序 —— 使用说明
================================================================

【这个程序是干什么的】
把"图纸材料表"PDF 自动变成中文"工艺清单"Excel。
程序认两种 PDF，自动判断，不用你选：
  ① 图片型 PDF（扫描/拍照的图纸，鼠标选不中文字）—— 国内图纸、阿瑞斯
  ② 文字型 PDF（鼠标能选中文字的）—— 瑞士、老外的清单
只要把文件夹摆对，双击运行.bat 就行。

【你需要准备的东西】
  1. 已装好 Python 环境（含程序所需依赖库）的电脑
  2. 这个程序文件夹（解压好的）
  3. 你的 PDF 文件

================================================================
第一步：把程序放到电脑上
================================================================
1. 把 工艺清单生成程序.zip 复制到这台电脑。
2. 右键解压，解压到哪里都行，比如：
   D:\工艺清单生成程序3. 解压后确认里面有这些文件（别的都别动）：
   - 运行.bat        ← 平时就双击它
   - run.py          ← 主程序
   - 工艺清单标准模版-2026.6.30(1).xlsx  ← 模板，不能删！

================================================================
第二步：整理 PDF 文件夹（最重要！摆错了就不出结果）
================================================================
按你的 PDF 类型二选一：

▶ 情况A：图片型 PDF（国内图纸、阿瑞斯这类）
   主清单 PDF 直接放文件夹里，文件名最好带"总图"两个字；
   子件 PDF 全部放进一个叫"分"的子文件夹里。像这样：
   D:\项目1     ├─ 时效炉炉体钢结构总图（图纸材料表）.pdf   ← 主清单
     └─ 分        ├─ 侧墙拉杆1（图纸材料表）.pdf            ← 子件
        ├─ 上风箱（图纸材料表）.pdf
        └─ ...（有多少放多少）

▶ 情况B：文字型 PDF（瑞士/老外的清单）
   把所有 PDF 直接放进同一个文件夹就行，【不要】建"分"文件夹：
   D:\瑞士项目     ├─ SL-1681-367-29182_Hopper_1....pdf
     ├─ SL-1681-367-29183_Hopper_2....pdf
     └─ ...

一句话记法：
   图片型的 → 主清单放外面，子件放"分"文件夹里
   文字型的 → 直接全放一个文件夹，不用分

================================================================
第三步：运行程序（每次做清单都这样）
================================================================
1. 双击 运行.bat。
2. 黑窗口提示"请输入清单文件夹的完整路径"。
3. 【把整个文件夹拖进黑窗口】再松手，路径会自动填好，
   不用手打。（拖不了就手输，例如 D:\项目1）
4. 按回车。
5. 开始跑，别关窗口，耐心等：
   - 图片型会显示 [OCR] 文件名 ... 和"正在做高倍率复核..."
   - 文字型会显示"检测到文字型 PDF（Rowa/瑞士格式）"
6. 看到"完成! 输出: 工艺清单_xxx（图号）.xlsx"就是成功了。
7. 按任意键关窗口。

（也可以直接把清单文件夹拖到 运行.bat 图标上，松手即运行。）

================================================================
第四步：拿结果 + 看复核报告（每次都要看）
================================================================
打开你输入的那个文件夹，会看到两个新东西：

1. 工艺清单_设备名称（图号）.xlsx ← 这是要交出去的清单
2. 复核报告.txt ← 程序自己做的质量检查，自动生成

【复核报告怎么看】（30秒的事）
- 报告里只有"程序自己查出来有疑问"的格子，没有疑问就不会列。
- 每行格式：第几页 | 部件名 | 数量/重量/规格: 原识别=xxx 高倍率=xxx
- 重点看 数量 和 规格 两列：
  如果高倍率读出的是数字、原来的是别的（比如 6 和 9 弄混、
  少了Ø 等），说明识别有错，直接在 Excel 里手动改正确即可。
  如果只是 1 和 L 这类小差别，基本是正常误差，不用管。
- 看完确认没有明显错误，再把 Excel 发出去。

================================================================
第五步：常见问题（对号入座）
================================================================
1. 提示保存失败 / 生成的文件打不开
   → 正用 WPS/Excel 开着旧文件呢。先关掉它，再重新运行。
     程序也会自动改存为"（新）.xlsx"，找到那个文件就行。

2. 识别出来的字有错（OCR 不可能100%对）
   → 对照原 PDF 手动改。数量/重量/规格优先看复核报告。

3. 子件没有展开，全是空的
   → 检查子件 PDF 是否放在了叫"分"的文件夹里。

4. 第二次跑同一个文件夹特别快
   → 正常，程序记住了上次的识别结果（缓存）。
     如果 PDF 更新过了，删掉程序目录下 data\ 里的对应子文件夹，
     再跑一次就会重新识别。

5. 主清单里引用了别的项目的图号（如 A300 引用 GDL130-Q300-20）
   → 把相关的项目文件夹放在同一个目录下（如都放在 E:\李鑫宇\ 里），
     程序会自动去旁边的"分"文件夹里找。

6. 程序提示"无法读取PDF（可能被WPS损坏）"
   → 那份 PDF 被 WPS 加密/损坏了，从原始来源重新拷贝一份
     （不要用 WPS 打开保存它），再重新运行。

================================================================
【绝对不要做的事】（记住这4条，就不会出问题）
================================================================
1. 运行前先关掉 WPS/Excel 里打开的旧工艺清单（会锁文件）。
2. 不要删/改 工艺清单标准模版-2026.6.30(1).xlsx（程序靠它出格式）。
3. 不要把子件 PDF 直接丢在主文件夹里（要放"分"文件夹）。
4. 运行过程中不要关黑窗口。
5. 不要用 WPS 保存任何 PDF/Excel 源文件（会被加密损坏）。

================================================================
程序文件说明
================================================================
- 运行.bat          双击这个（输入文件夹路径，或直接把文件夹拖到图标上）
- run.py            主程序（自动判断PDF类型→识别→生成Excel）
- swiss_build.py    文字型PDF（瑞士）翻译排版
- build_output.py   Q300/A300 独立生成器（一般用不到）
- 工艺清单标准模版-2026.6.30(1).xlsx  模板（不能删）
- requirements.txt  依赖库清单（本机已装好则无需处理）
- data\             识别缓存（可删，删了会重新识别）
