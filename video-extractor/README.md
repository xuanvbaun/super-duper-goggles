# 视频提取与转换工具

## 使用方法

1. 双击 `启动下载面板.bat`，浏览器会打开 `http://localhost:8765`。
2. 在面板中粘贴 B 站视频地址，解析后选择需要的清晰度下载。
3. 需要转换本地视频时，将文件拖到 `转换MP4.bat` 上。

## 环境要求

- 下载面板需要 Node.js。
- 视频合并和格式转换需要 FFmpeg；程序会先查找系统 FFmpeg，再查找本目录的 `ffmpeg\bin\ffmpeg.exe`。
- 启动脚本使用自身所在目录，不依赖固定盘符或文件夹。
- 面板只监听本机 `127.0.0.1:8765`，不会向局域网开放下载接口。
- 转换失败时页面会显示实际错误；大文件结果采用流式下载，不会一次性读入内存。
